# THE BRIDGE Web

The interactive cockpit for THE BRIDGE, built with Next.js, React, Tailwind CSS,
and shadcn/ui.

Run it from the repository root:

```bash
pnpm dev:web
```

The application is available at `http://127.0.0.1:3100` and calls the local API
at `http://127.0.0.1:3101/api` by default. Copy `.env.example` to `.env.local` to
override the API URL.

See the [root README](../../README.md) for setup, architecture, contribution,
GitFlow, and commit conventions.
